    HTTPS inspection CA

    MITM

    Proxies with MITM on decrypt HTTPS so you can see headers and bodies. The client device must trust this CA certificate, otherwise TLS handshakes fail (you will see that as an error in Traffic).

    ⬇ Download ca.crt
    How to install the CA
    • Windows: double-click ca.crt → Install Certificate → Local Machine → "Trusted Root Certification Authorities".
    • macOS: open in Keychain Access → System → set "Always Trust".
    • Ubuntu/Debian: sudo cp ca.crt /usr/local/share/ca-certificates/ppm.crt && sudo update-ca-certificates
    • Android: Settings → Security → Encryption & credentials → Install a certificate → CA. (Apps only trust user CAs if they opt in.)
    • iOS: install the profile, then Settings → General → About → Certificate Trust Settings → enable.
    • curl: curl --cacert ca.crt -x http://user:pass@host:port https://example.com
    • Node.js: NODE_EXTRA_CA_CERTS=ca.crt · Python requests: REQUESTS_CA_BUNDLE=ca.crt
